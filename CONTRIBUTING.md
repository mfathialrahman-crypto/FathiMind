# Contributing

FathiMind prefers a small number of real changes.

1. Read [docs/architecture.md](docs/architecture.md) and [docs/rfcs.md](docs/rfcs.md).
2. Contract or cross-repo changes need an RFC first.
3. Do not add ornamental commits, generated noise, or undocumented secrets.
4. Runtime code lives in HelixMind, MFR-Cognition, AetherMind, SovereignEvolution — not in this handbook unless it is a schema or docs.
5. Tests belong with the runtime they protect (`test-foundation`).
